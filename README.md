# 🎯 CGPA Goal Calculator using Excel Goal Seek

This mini-project demonstrates how to use **Excel Goal Seek** to calculate the **required semester score** to reach a target **CGPA (Cumulative Grade Point Average)** based on your previous **SGPA** performance.

Many universities calculate CGPA using a **weighted average of SGPA** from each semester. With the right data in Excel, you can easily estimate:

- Whether your **desired CGPA** is achievable
- The **exact grade/SGPA** needed in the current semester to reach that CGPA
- How **semester credits (weights)** affect your final results

## 📌 Features

- Clean Excel sheet with SGPA and credit inputs  
- Built-in CGPA calculation formula  
- Excel **Goal Seek** used for target CGPA estimation  
- Works with any university grading system that uses weighted SGPA  
- Fully editable and reusable for students  

---

## 🧮 How It Works

1. Enter:
   - Each semester's **SGPA**
   - The corresponding **credit weight**

2. Define your **target CGPA**

3. Run **Goal Seek**:
   - Go to **Data → What-If Analysis → Goal Seek**
   - Set the target CGPA cell to your desired value
   - Select the **current semester SGPA** as the variable cell

Excel will automatically calculate the **minimum SGPA** you need in your current semester to reach your goal.
